# 同屏 2.6.7

Windows 11 小群语音与屏幕共享，建议 3–4 人使用。

## 2.6.7

远程操作者停止控制后清除协作光标。最后一位操作者退出时释放键鼠输入并关闭辅助进程。

## 2.6.6

点窗口右上角的 × 会收进系统托盘，同屏继续接收来电，进行中的通话也会继续。点击托盘图标恢复窗口，右键菜单里的「退出同屏」可以彻底退出。

## 2.6.5

联系人呼叫会区分对方取消、进房失败和信令断开。房间只剩自己时显示等待朋友加入。导出的诊断日志包含纯语音通话的延迟、丢包和缓冲数据。

## 2.6.4

可用上行长期偏低、连接稳定时，短暂给视频留出额外带宽来探测恢复情况。探测期间保持画质档位，丢包或延迟上升时取消。

## 2.6.3

可用上行较低时，自动为每位接收方调整分辨率、帧率和码率。连接详情显示上行估计、发送目标和实际发送数据。

## 2.6.2

每次打开同屏都会从 GitHub Releases 检查更新。新版本通过签名和文件校验后会在后台下载，空闲时自动安装并重新打开。通话、共享和文件传输结束后才会重启。可以在「设置 → 关于与更新」关闭自动安装，也可以手动选择轻量更新 ZIP。

## 2.6.1

旧的耳机或扬声器失效时，自动切换到系统默认输出，仍可进入房间。联系人通话接通后再打开麦克风，麦克风不可用时仍可留在房间。

诊断日志从软件启动开始记录。遇到报错可点提示里的「导出诊断日志」，也可随时从「设置 → 关于与更新」导出 JSON。日志按时间记录进房、信令、音频设备、共享、文件传输、远程协作和更新等故障。程序启动失败时，可在安装目录的 `.run/diagnostics` 找到记录。

日志仅保存在本机，最多保留最近 7 天和 8 个文件。导出内容包含应用版本、错误类别和相关步骤，使用固定字段，省略房间号、昵称、设备 ID、IP 地址和文件路径。需要协助排查时，可以手动发送导出的文件。

## 新增

- 固定联系人：左侧复制自己的好友码，朋友添加一次即可。在线时点「呼叫」，对方接听后自动进房并开麦；正在通话时可以再呼叫朋友加入。共享屏幕仍需各自点击。
- 来电响铃、接听、拒绝、取消、忙线和超时。客户端开着或最小化才能收到来电，彻底退出后离线。呼叫信令目前依赖 MiroTalk 公共站的可用性。
- 共享声音最大 100%，语音音量可增强。分别记住每位联系人的语音、共享声音和静音状态，下次连接自动恢复。
- 更新只接受发布者签名的轻量更新包。GitHub 暂时不可访问时，可继续使用当前版本。
- 保留小窗、全屏、一键静音、P2P 文件传输、经对方同意的远程协作、屏幕共享日志和视频带宽优化。

## 启动

完整解压 ZIP，然后双击 Start-Friends.cmd，不要在压缩包内运行。

首次打开设置昵称。公开全量包会生成一个随机房间，复制邀请链接给朋友即可加入。升级用户可继续进入原先的房间，也可以互加好友码后呼叫。

## 从旧版升级

2.6.0 和 2.6.1 用户可在「设置 → 关于与更新」选择轻量更新 ZIP，升级一次后启用自动更新。旧桌面版也可退出软件，解压轻量包后运行 Update-Friends.cmd 并选择已有客户端目录。新用户下载全量包。

更新会保留运行时、系统用户配置、日志与现有房间设置；旧文件备份在客户端 .rollback 文件夹。通话中不会自动安装。

## 画质与连接

默认目标 1080p60，自适应优先稳定 30 帧，网络和编码余量允许时恢复 60 帧。实际画质仍受上行、编码负载、丢包及直连/中继路径影响。左下角「连接详情」可标记问题并打开匿名共享日志。

音频沿用原有防回音与 RNNoise 降噪处理。共享采集排除同屏自身声音；扬声器回声仍受房间和音量影响。
