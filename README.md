# 同屏 · Windows

小群语音、双向屏幕共享、点对点文件传输和经授权的远程协作。适用于 Windows 11 x64。

从 [Releases](https://github.com/sho777564/friends-screenshare/releases/latest) 下载。新用户解压 `Windows11.zip`，双击 `Start-Friends.cmd`。打开后进入房间并复制邀请链接发给朋友。

2.6.0 或 2.6.1 用户可以从「设置 → 关于与更新」选择 `Update.zip` 安装。2.6.2 起每次启动都检查更新，有新版时后台下载，空闲后校验、安装并重新打开。

客户端源码在 `public`、`desktop` 和 `native`。Windows 安装包附带 Electron 运行时和许可证，依赖来源见 `SOURCES.json`。公开全量包首次启动生成随机房间。诊断日志保存在本地，可在软件内导出。

详细用法见 [README-先看这里.md](README-先看这里.md)。
